Задача I: Бесплатно
Условие задачи (pdf)

В честь десятилетия зала администрация решила разыграть годовой абонемент. Но администрации показалось, что раздавать случайно такой приз скучно, поэтому она решила выдать абонемент человеку, решившему данную задачу быстрее всех:

Дано дерево, состоящее из
вершин. Некоторые из вершин помечены. Нужно ответить на
следующих вопросов:

Даны два числа
. Требуется сказать минимальную длину пути, который начинается в вершине
, заканчивается в вершине
и посещает каждую отмеченную вершину.

Саша очень хочет сэкономить, поэтому просит вас решить эту задачу как можно быстрее.

Формат входных данных
В первой строке записаны два числа
(
) — количество вершин в дереве и количество вопросов, на которые нужно ответить.

Во второй строке записаны
чисел
(
). Если
, то вершина
помечена, иначе нет.

В следующих
строках записаны описания вершин дерева. Каждое ребро задается двумя числами
(
). Гарантируется, что ребра образуют дерево.

В следующих
строках записаны описания вопросов. Каждый вопрос задается двумя числами
(
) — номер вершины, где должен начинаться путь, и где он должен заканчиваться.

Формат результата
На каждый вопрос выведите ответ на него в отдельной строке.
