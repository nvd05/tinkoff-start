Задача B: Шахматы
Условие задачи (pdf)

Кирилл давно хотел заняться спортом. И, проведя небольшое исследование, он выбрал для себя идеальный вид спорта — шахматы. Чтобы научиться играть в шахматы, Кирилл начал с шахматных загадок. Но на одной из них он застрял:

Дана шахматная доска размером
. Сколько вариантов поставить на ней
коня так, чтобы они не били друг друга.

Помогите Кириллу ее решить, пока он не забросил идею заняться спортом.

Формат входных данных
В единственной строке записано одно число
(
) — размер доски.

Формат результата
Выведите одно число — количество способов поставить
коня на доску размера
, чтобы они не били друг друга.
