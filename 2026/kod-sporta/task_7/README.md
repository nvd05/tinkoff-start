Сдать решение задачи G-Блины в спортзале
Ограничение времени:	2 с
Ограничение реального времени:	5 с
Ограничение памяти:	512M
Задача G: Блины в спортзале
Условие задачи (pdf)

В школьном спортзале стоят две стопки блинов для штанг. В первой стопке находится
блинов, а во второй
блинов.

Петя и Саша решили устроить игру: они будут снимать блины по очереди. Первым ходит Петя. За один ход игрок обязан сделать ровно одно из действий:

Снять любое положительное количество блинов с первой стопки.

Снять любое положительное количество блинов со второй стопки.

Снять одинаковое положительное количество блинов с обеих стопок.

Проигрывает тот, кто не может сделать ход.

Определите, кто выиграет в этой игре, если каждый из игроков играет оптимально.

Формат входных данных
Данная задача состоит из нескольких наборов входных данных. В первой строке записано число
(
) — количество наборов входных данных. Далее идет их описание.

В единственной строке каждого набора входных данных записано два целых числа
(
) — количество блинов в первой и второй стопках.

Формат результата
Для каждого набора входных данных выведите first, если выигрывает игрок, делающий первый ход, иначе выведите second.

Примеры
Входные данные
5
5 3
2 1
2 2
4 3
4 5
Результат работы
second
second
first
first
first
