
# Описание таблиц.docx

1) Таблица students

> Описание: Таблица хранит информацию о студентах онлайн-платформы обучения.

Столбцы:

+ student_id — уникальный идентификатор студента (TEXT).
+ full_name — ФИО студента (TEXT).
+ city — город (TEXT).
+ signup_date — дата регистрации (DATE).

Пример данных:

| student_id | full_name       | city     | signup_date |
|------------|-----------------|----------|-------------|
| S1         | Иван Смирнов    | Москва   | 2026-01-05  |
| S2         | Мария Иванова   | Казань   | 2026-01-12  |
| S3         | Сергей Кузнецов | Омск     | 2026-01-20  |

2) Таблица enrollments

> Описание: Таблица хранит записи студентов на курсы и текущий статус прохождения.

Столбцы:

+ enroll_id — уникальный идентификатор записи на курс (TEXT).
+ student_id — идентификатор студента (TEXT), соответствует students.student_id.
+ course — название курса (TEXT).
+ enroll_date — дата записи на курс (DATE).
+ progress_pct — прогресс прохождения в процентах (INT, от 0 до 100).
+ status — статус обучения (TEXT), например: completed, in_progress, cancelled (может быть NULL).

Пример данных:

| enroll_id | student_id | course     | enroll_date | progress_pct | status      |
|-----------|------------|------------|-------------|--------------|-------------|
| E1        | S1         | SQL Basics | 2026-02-01  | 100          | completed   |
| E2        | S1         | Python     | 2026-02-10  | 40           | in_progress |
| E3        | S2         | SQL Basics | 2026-02-03  | 0            | cancelled   |

3) Таблица reviews

> Описание: Таблица хранит отзывы студентов по конкретным прохождениям курсов (по записи enrollments).

Столбцы:

+ review_id — уникальный идентификатор отзыва (TEXT).
+ enroll_id — идентификатор записи на курс (TEXT), соответствует enrollments.enroll_id.
+ rating — оценка (INT) по шкале 1–5.
+ review_date — дата отзыва (DATE).

Пример данных:

| review_id | enroll_id | rating | review_date |
|-----------|-----------|--------|-------------|
| R1        | E1        | 5      | 2026-02-02  |
| R2        | E3        | 3      | 2026-02-05  |
