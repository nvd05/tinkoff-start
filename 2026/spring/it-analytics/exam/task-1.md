
# 1 задание | 100 баллов

+ Ограничение времени: `1 секунда`
+ Ограничение памяти: `128 МБ`

Напишите запрос, который выведет сколько студентов завершили хотя бы один курс.
Завершённым считается обучение со статусом status = 'completed'.

[Описание таблиц.docx](Описание%20таблиц.docx.md)

```sql
SELECT COUNT(DISTINCT student_id) AS completed
FROM enrollments
WHERE status = 'completed';
```
